# MTeam 卡片管家 (MtCardManager)

MoviePilot V3 插件：M-Team 收藏卡管理。

- **总览**：卡片数 / 薪王 / UR / 守护濒危 / 完成卡册 / 段位
- **重复卡挂单**：同片同稀有度留 1 张（优先薪王），建议价=同款最低3档中位，三价对照（我的挂牌价 < 近期成交价标红防秒扫），挂单强制预览确认
- **我的成交**：成交笔数 / 净收入 / 手续费 / 逐笔明细

合规：只用 x-api-key（MP 站点配置），不碰 Cookie/JWT；只调 /api/pt-card/** 白名单；限流 ≤1 req/s；无自动买卡/分解/撤单。

前置：MP「站点管理」→ 馒头 → 已填写 apikey。

# MTeam 卡片管家 — 安装说明

## 安装
1. 打开 MP → 插件 → 本地安装（右上角「···」→ 安装本地插件），选择 `MtCardManager.zip`。
2. 前置条件：MP「站点管理」→ 馒头 → 已填写 **apikey**（控制台→实验室→存取令牌获取）。插件只读这个 Key，不碰 Cookie/JWT。
3. 装好后启用插件，进入「MTeam 卡片管家」页签。

## 页面
- **总览**：卡片数 / 薪王 / UR / 完成卡册 / 排名，30 分钟自动刷新。
- **重复卡挂单**：同片同稀有度留 1 张（优先留薪王），显示建议价（同款最低3档中位）+ 市场最低 + 近期成交三价对照；**我的挂牌价 < 近期成交价会标红"可能被秒扫"**，可一键撤单改价。挂单走强制预览确认。
- **我的成交**：成交笔数 / 净收入 / 手续费（5%）汇总 + 逐笔明细。

## 合规
- 只用 `x-api-key`，不发送 Cookie/Authorization/JWT（代码里单一 Session 工厂，审计点在 `_get_session`）。
- 只调用 `/api/pt-card/**` 白名单端点（`ALLOWED_ENDPOINTS`），member/msg/admin/login 全部拒绝。
- 全局令牌桶限流 ≤ 1 req/s，行情刷新 ≥ 30 分钟。
- 不做自动买卡、自动分解、自动撤单；所有写操作有预览确认。

## 文件
- `__init__.py` — 后端（MP 插件 V2 规范）
- `dist/Main.vue` — 前端三页签
- `package.json` — 插件元信息
